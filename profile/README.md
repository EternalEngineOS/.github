EternalEngine is a full-stack, multi-tenant SaaS platform: one login and one bill for the
17 applications a service business would otherwise buy separately — CRM, invoicing and
estimates, scheduling, email, payments, projects, and an AI assistant, plus a growing
catalog of add-on apps. It is built for one-person shops through growing teams — plumbers,
electricians, landscapers, cleaners, HVAC, construction, field service, and professional
services — and it is priced to match: **Free at $0**, **Basic at $9.95/month**.

This organization publishes what a customer, integrator, or security researcher needs from
the outside: documentation, changelogs, our security policy, and the public roadmap. The
product itself — the application code — is closed source and lives in a private repository.

## How we build

EternalEngine is built and operated by a small team running a governed fleet of AI
agents under human review — every change passes an automated engineering gate before it
ships, and the platform's security posture is described in full on our
[security page](https://eternalengineos.io/security). The product's source code stays
private; this organization is where we publish the documentation, changelog, security
policy, and roadmap that describe it from the outside.
