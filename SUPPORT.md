# Support

## Self-serve, fastest

- **Pricing and plan limits** — every limit is on the [pricing page](https://eternalengineos.io/pricing).
- **Is something down** — [system status](https://eternalengineos.io/status).
- **What shipped recently** — [changelog](https://eternalengineos.io/changelog).
- **Data export or deletion requests** — [your data & requests](https://eternalengineos.io/data-requests).
- **Want to see it first** — [request a demo](https://eternalengineos.io/demo).

## Talk to us

- **General support and sales** — email [info@eternalengineos.io](mailto:info@eternalengineos.io),
  or use the [contact form](https://eternalengineos.io/contact).
- **Security reports** — see [`SECURITY.md`](SECURITY.md); do not use this channel for
  vulnerability reports.
- **Community** — ask in [GitHub Discussions](https://github.com/orgs/EternalEngineOS/discussions),
  or use ThreadRealm inside the app once you have an account.

## Response time

We read every message and aim to reply within one business day. Sales and volume
questions get priority.

## This repository

For issues with the documentation or policies published in this repository specifically
(not the product), open a GitHub issue here using the templates under
[`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/).
