# Contributing

Thanks for your interest in EternalEngine. Please read this before opening an issue or
pull request here.

## What this repository is

This is the EternalEngine organization's community-health repository — the org profile,
policies, and public documentation. It is **not** the product. The application code for
ClientForge, PayGate, PostFrame, and the rest of the platform is closed source and lives in
a private repository. **We do not accept code contributions to the product through GitHub**
— there is no public repository to open a product pull request against.

## What you can contribute here

- **Bug reports** — something in the product is broken. Use the
  [bug report template](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature requests** — something you wish the product did. Use the
  [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml). Note: customers
  can also post these directly in-product, in ThreadRealm, where the product team already
  triages them.
- **Documentation fixes** — a typo, a broken link, an inaccurate statement in any `.md`
  file in this repository. Open a pull request directly; see the
  [PR template](.github/PULL_REQUEST_TEMPLATE.md). Doc PRs are the one kind of code change
  we do accept here, because this repository *is* the documentation.

## What we don't accept

- Pull requests against product code — there is nowhere to send them; the product
  repository is private.
- Security vulnerability reports as public issues — see [`SECURITY.md`](SECURITY.md)
  instead.

## Response expectations

We read every issue and pull request. Documentation PRs and bug reports get a first
response within a few business days. We don't yet publish a formal SLA for this repository;
if that changes, it will be recorded here.

## Questions

For anything else, see [`SUPPORT.md`](SUPPORT.md) or [contact us](https://eternalengineos.io/contact).
